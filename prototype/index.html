About this prototype

The shortlist is picked by hand, not computed. This is a wizard of oz prototype. A person searched, opened and verified every posting in it on 7 October 2026. There is no matching algorithm behind this page. We are testing whether a student accepts a shortlist as accurate before building anything that produces one.

Nothing you type leaves this page. No account, no upload, no CV, no server, no cookies, no analytics. Your answers live in the browser tab and disappear when it closes. That is a deliberate design position, not a shortcut: see evidence-log/privacy.md.

Deadlines are shown, never guessed. Where an employer states no closing date, the card says so instead of claiming the role is open. Test run 01 found that an AI asked to judge whether a posting was open got it wrong on two of the first three it read, so that judgement was taken away from the model.
