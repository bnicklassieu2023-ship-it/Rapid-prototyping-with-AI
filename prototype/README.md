# Prototype

**This folder is deliberately empty until Session 16.**

The course repository structure keeps `prototype/` empty until the first build starts in Session 16. Nothing belongs here before then, and nothing is here.

## Why this file exists at all

Two things were removed from this folder on 8 October 2026, and the record of why is more useful than a silent deletion.

A working HTML page had been generated with AI and committed here, described as our rough prototype v0.2, along with a scoring sheet and an earlier PDF and PNG. The team has not built a prototype. Presenting a generated page as our own artefact is exactly the thing this repository is supposed to make impossible, so it came out, together with every claim elsewhere in the repository that a built prototype existed.

The full entry is number 19 in [../evidence-log/decision-log.md](../evidence-log/decision-log.md).

## What this means for the critical test

The graded feedback scored Rough Test 0 out of 0.8 with "add the actual rough prototype and a backup". That is still owed, and it is not answered by anything in this folder.

The rough prototype for [test run 03](../evidence-log/test-runs/run-03-student-trust-test.md) will be a sketch of six cards, one per verified opening found in [test run 01](../evidence-log/test-runs/run-01-shortlist-feasibility.md), made by the team and shown to students on paper or on a slide. It does not need to be built software, and the course is explicit that no major build is needed to start testing.

Until that sketch exists, the student trust test is designed and not runnable, and the repository says so rather than implying otherwise.
