# Test runs

Every test this team has actually run, and every test it has designed but not run, with the two kept clearly apart.

This folder exists because of the graded feedback on the previous submission. The Experiment fit criterion read: "You have designed a runnable test, but you have not run it." The fix is not more design. It is running things and writing down what happened, including when the result is inconvenient.

## How to read a run file

Every run file states who ran it, on what date, what kind of run it was, what the result was, **what the result works against us**, what it does not show, and what decision was taken from it. A run with no "works against us" section has not been read honestly enough.

## The line this folder does not cross

Runs 01 and 02 are desk runs carried out with AI assistance. They produce checkable facts: URLs, deadlines, prices, HTTP status codes. Anyone can open the raw file and re-check them.

They are **not** user evidence. No desk run, no AI persona and no synthetic answer is ever counted as a student having told us something. The only user evidence in this repository comes from real people: one filmed interview so far ([../user-feedback.md](../user-feedback.md)), the live survey, and run 03 once it happens. See [../persona-agent-rehearsal.md](../persona-agent-rehearsal.md) for the one time we ran synthetic personas and threw the agreeable half of the output away.
